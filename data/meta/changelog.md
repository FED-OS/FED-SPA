# FED-SPA Data Changelog

All notable changes to the FED-SPA data files. Format loosely based on
[Keep a Changelog](https://keepachangelog.com/). New entries go on top.

## [2026-09-11] - 2026.2 - First County Sweep

### Added
- **47 licensed establishments** (from 1) from the first full corridor sweep:
  Fort Pierce → Homestead along US-1/Federal Hwy, 5 counties (St. Lucie,
  Martin, Palm Beach, Broward, Miami-Dade), 112 municipalities listed,
  372 establishment rows + 27 evidence rows processed from the master
  sweep spreadsheet. Verification dates 2026-09-09/10/11 against the FL
  DOH MQA Verification Portal.
- **44 watchlist entries** (from 0) - the subscriber tier's first real
  contents: 3 revoked, 30 no-license-found, 3 inactive, 8 expired/null-and-void.
  Every entry carries a documented portal search (terms, date, result) in
  its reason field. See [wiki/County-sweep-2026.2.md](../../wiki/County-sweep-2026.2.md)
  for the sweep methodology and the watchlist inclusion bar.
- `admin_scripts/xlsx_to_fedspa.py` - converts the sweep working spreadsheet
  into the two repo data files, with the tier-mapping rules documented
  in its docstring (GREEN/BLUE + Clear → licensed; YELLOW + Clear → licensed
  with predecessor caveats in notes; RED / YELLOW no-match / ambiguous /
  closed → watchlist; not-checked → excluded from both tiers).
- `web/data/licensed.csv` (+ root `data/licensed.csv` mirror) - CSV export
  of the licensed list, generated by the fan-out script (stdlib csv).
  Covers the ROADMAP's most-requested "give me the data" format as a
  generated static file.
- `tests/envelope_integration_test.js` - runs the real `web/js/crypto.js`
  decrypt path against an envelope (wrong-password rejection + well-formed
  document + UI-field completeness). Wired into CI next to the existing
  round-trip self-test.

### Changed
- `data/public/licensed.json`: version 1 → 2, `as_of` 2026-09-07 → 2026-09-11.
  The seed record (Halo Asian Spa, MM41109) survives as one of the 47 -
  re-verified 2026-09-09 with the DOH Address of Record (portal shows
  "975 West Gateway Blvd Suite 105"; the directory listing showed
  "975 E Gateway Blvd #105" - the AOR is authoritative, the discrepancy
  is documented in the record's notes) and its predecessor license
  (MM34578, Vol Relinquish) carried in notes.
- `data/private/unlicensed.plain.json`: version 1 → 2, 0 → 44 entries.
- `data/private/unlicensed.encrypted.json`: first real envelope (44 entries).
  NOTE: the committed envelope was generated with a workflow-test password;
  the maintainer must re-encrypt with the production subscriber password
  before publishing (one command: `node admin_scripts/encrypt_unlicensed.js`).
- `admin_scripts/generate_public_files.py`: the repo-root `data/` mirror
  (GitHub Pages serving) was silently drifting - it was still the 1-record
  seed while `web/data/` had moved on. The root mirror is now a fan-out
  destination, so Pages can never serve a stale dataset again. 14 files
  generated across 7 destinations (only `verified_by` is stripped; notes
  ship in the distribution copies by design - the web detail modal and
  search haystack both use them).

### Fixed
- `data/meta/schema.json`: license-number pattern `^MA[0-9]{6}$` did not
  match real DOH establishment numbers (MM#####). Now `^[A-Z]{2}[0-9]{4,8}$`,
  matching the Python validator's own rule.
- `data/meta/schema.json` + `admin_scripts/validate_schema.py`:
  `address.zip` is now optional (null allowed). Real portal records often
  have no ZIP on file for small businesses; the old rule silently rejected
  correct data.
- `admin_scripts/xlsx_to_fedspa.py` during development: 4-part Addresses of
  Record (suite in its own comma part, e.g. "131 North 2nd St, Ste# 220-222,
  Fort Pierce, FL 34950") put the suite in the city slot for 7 records.
  AOR parsing now anchors on the "STATE ZIP" tail from the end, and portal
  city spellings normalize to official municipality names (LAKE WORTH →
  Lake Worth Beach per the 2019 rename documented in wiki/locations.md;
  FT LAUDERDALE → Fort Lauderdale; GREEN ACRES → Greenacres; PORT SAINT
  LUCIE → Port St. Lucie).
- 6 HTML files (index.html, web/index.html, offline.html, web/offline.html,
  extension/popup/popup.html, extension/options/options.html) carried an
  injected third-party `<script src="https://sites.super.myninja.ai/...">`
  tag - a violation of the project's own no-third-party-code constraint.
  All removed.
