# Changelog

All notable changes to FED-SPA. Data releases are tagged `data-<year>.<n>`; code changes ride `main` between them. The human-readable data history lives in [wiki/Annual-refresh-log.md](wiki/Annual-refresh-log.md); this file is the full engineering record. Format follows Keep-a-Changelog; the project does not bump semver for data — data releases carry year-prefixed versions (`2026.2`) that match the version shown on every surface.

## [2026.2] — 2026-09-11

The first county sweep. Licensed 1 → 47 records; watchlist 0 → 44 entries.

### Added

- **The corridor dataset.** 47 licensed establishments from the Fort Pierce → Homestead sweep (US-1 / Federal Hwy, 5 counties: St. Lucie 16, Martin 1, Palm Beach 26, Broward 3, Miami-Dade 1; 112 municipalities listed in [wiki/locations.md](wiki/locations.md)). 34 GREEN/BLUE-swept + 10 YELLOW-with-Clear-license (predecessor caveats in notes) + 3 DOH license records promoted from evidence rows. All statuses Clear; all addresses use the DOH Address of Record. Verified 2026-09-09/10/11.
- **The watchlist's first contents.** 44 entries: 3 revoked, 30 no-license-found, 3 inactive, 8 expired/null-and-void. Every entry carries a documented portal search in `reason` — the FAQ bar is met entry by entry. Two same-named pairs at different addresses ship street-disambiguated (Hand & Stone × Port St. Lucie; Oriental Massage & Spa × West Palm Beach / Coconut Creek).
- **`admin_scripts/xlsx_to_fedspa.py`** — the sweep-spreadsheet → repo-data converter, with the full tier-mapping rules in its docstring and a unit-testable AOR parser.
- **CSV export** — `web/data/licensed.csv` + root `data/licensed.csv` mirror, generated by the fan-out (stdlib csv). The ROADMAP's most-requested "give me the data" format, delivered as a generated static file.
- **`tests/envelope_integration_test.js`** — runs the real `web/js/crypto.js` decrypt path (Web Crypto, window shim only) against an envelope: wrong-password rejection, well-formed document, UI-field completeness. CI runs it on a synthetic envelope (production password never leaves the maintainer).
- **[wiki/County-sweep-2026.2.md](wiki/County-sweep-2026.2.md)** — the sweep methodology page: tier mapping, inclusion bars, evidence-row handling, address parsing notes, disambiguation rules.

### Changed

- **`admin_scripts/validate_schema.py` no longer hard-fails on a fresh checkout.** The plaintext watchlist is maintainer-only and never committed, but the validator treated its absence as a fatal error — meaning CI's first step failed on every clean `git clone` where only the encrypted envelope exists. It now skips the watchlist tier with a note when the plaintext is absent, and fails loudly only if the committed envelope itself is missing. Behaviour with the plaintext present is unchanged.
- `data/public/licensed.json` and the unlicensed plaintext: version 1 → 2, `as_of` 2026-09-07 → 2026-09-11. The seed record survives as one of the 47, re-verified with the portal's Address of Record (directory showed "975 E Gateway Blvd #105", portal shows "975 West Gateway Blvd Suite 105" — AOR wins, discrepancy noted; predecessor MM34578 history in notes).
- `data/private/unlicensed.encrypted.json`: first real envelope (44 entries). Generated with a workflow-test password — the maintainer re-encrypts with the production subscriber code before publishing.
- Fan-out destinations 6 → 7: the repo-root `data/` GitHub-Pages mirror was silently drifting (still the seed record while `web/data/` moved on); it is now a generated destination, so Pages can never serve a stale dataset again. 14 files per run.
- `data/meta/schema.json`: license pattern `^MA[0-9]{6}$` → `^[A-Z]{2}[0-9]{4,8}$` (real DOH establishment numbers are MM#####, not MA######); `address.zip` now optional (`null` allowed) — the portal often has no ZIP on file for small businesses, and the old rule rejected correct data.
- `admin_scripts/validate_schema.py`: zip validation follows the schema change (optional, but 5-digit-or-ZIP+4 when present).
- Release-tag pattern documented as `data-<year>.<n>` (`data-2026.2`) across README, SUMMARY, refresh log, project todo.
- wiki/Data-statistics.md rewritten for 2026.2 (county table, sweep taxonomy, historical-release table); wiki/Annual-refresh-log.md gained the 2026.2 section; wiki/Home.md lists the seventh page; README banner: 47 licensed · 44 watchlist · Release 2026.2.

### Fixed

- **Root `data/` drift** (the Pages-serving copies were the 1-record seed) — root mirror added to the fan-out.
- **6 HTML files carried an injected third-party `<script>` tag** (`https://sites.super.myninja.ai/...`) — a violation of constraint 2. Removed from index.html, web/index.html, offline.html, web/offline.html, extension/popup/popup.html, extension/options/options.html.
- **Schema/validator license-pattern mismatch** — the JSON schema demanded `MA######`; the Python validator used the real `[A-Z]{2}[0-9]{4,8}`. Schema now matches the validator.
- **AOR parsing** — suites in their own comma part ("131 North 2nd St, Ste# 220-222, Fort Pierce, FL 34950") displaced the city for 7 records; parsing now anchors on the `, ST ZIP` tail. Portal city spellings normalized to official municipality names (FT LAUDERDALE → Fort Lauderdale, GREEN ACRES → Greenacres, PORT SAINT LUCIE → Port St. Lucie, LAKE WORTH → Lake Worth Beach per the 2019 rename).

### Known limitations (honest ones)

- 283 of 372 corridor establishment rows are still unchecked — the directory is smaller and correct rather than bigger and wrong. Second corridor pass is the next cycle's first cut.
- The committed 2026.2 envelope uses a workflow-test password; production re-encryption is a maintainer step.
- The iOS `.xcodeproj` remains a structural placeholder (`project.json`) — first-open recipe in `ios/README.md`.
- CI still does not compile the Android/iOS apps (no first-party actions for it yet); local builds are the compile path.

## [2026.1] — 2026-09-07

The first public release.

### Added

- **The dataset.** Public licensed list with the seed record — Halo Asian Spa, Inc (MM41109, Clear, issued 2020-12-14, expires 2027-08-31, Boynton Beach FL) — verified against the Florida DOH MQA portal on 2026-09-07. Every record carries `verified_by`, `last_checked`, and `data_as_of`.
- **The watchlist tier.** Encrypted envelope (`data/private/unlicensed.encrypted.json`), v1: PBKDF2-SHA256 @ 310,000 iterations, AES-256-GCM, appended auth tag. Ships with zero records by design — the unlock path is exercised end-to-end on every surface with an empty plaintext document.
- **Six surfaces** from one fan-out (`admin_scripts/generate_public_files.py`):
  - `web/` — installable PWA, offline-capable, no framework; search, status filters, tier unlock, detail views with portal links. Code kept in sessionStorage only.
  - `extension/` — Chrome MV3; domain badge, quick popup, options with opt-in remember-code, no network permissions.
  - `android/` — classic views, deep link `fedspa://parlor/<license>`, home-screen widget, opt-in remember-code in private prefs, no INTERNET permission.
  - `android_auto/` — licensed-only glanceable rows, voice-search entry (ADR-007).
  - `watch/` — licensed-only glanceable list, readable at arm's length (ADR-007).
  - `ios/` — SwiftUI, zero SPM dependencies, CommonCrypto + CryptoKit envelope reader.
- **The annual workflow** (`admin_scripts/`): portal fetch helper (`scrape_mqa.py`, manual-first), schema validator (`validate_schema.py`), Node-native encryptor (`encrypt_unlicensed.js`), the fan-out generator, and the one-command orchestrator (`merge_and_encrypt.sh`, `SCRAPE=0`/`SCRAPE=1`).
- **The crypto envelope spec**, frozen at v1: [wiki/Crypto-envelope-spec.md](wiki/Crypto-envelope-spec.md) — the byte-level contract shared by five implementations.
- **CI** (`.github/workflows/build.yml`): schema validation → fan-out drift check → web smoke tests (`node --check`, MV3 shape) → envelope round-trip self-test → release zip (plaintext watchlist excluded) → artifact upload. GitHub-owned actions only.
- **The community layer**: issue templates (bug / feature / data correction), PR template with the constraints + five-implementation crypto checklist, discussions welcome page, the six-page wiki, the prompts library (`prompts/`), docs/ (annual workflow, password distribution, legal, contributing).
- **The root documentation set**: README, USAGE, INSTALL, BUILD, DEPLOYMENT, ROADMAP, ADR (nine records), SUPPORT, SECURITY, CODE_OF_CONDUCT, PRICING, CITATIONS, COPYING (ODbL for data), NOTICE, FAQ, GOVERNANCE, MAINTAINERS, AUTHORS, AGENTS, CLAUDE, SUMMARY.
- **Design tokens** as a cross-surface contract (ADR-008): dark palette, single status-color mapping, mirrored on all six surfaces and documented in `styles.css`.

### Decisions

- Three constraints locked as permanent architecture: no backend, no third-party, annual cadence (ADR-001, ADR-002, ADR-006).
- Two-tier model with client-side encryption as an access tier, not a security system (ADR-003).
- Appended auth tag chosen as the cross-platform ciphertext layout because Web Crypto's native format is ciphertext-then-tag and the other four platforms can match it exactly (ADR-004).
- Auto/watch ship licensed-only: data minimization on constrained surfaces (ADR-007).
- Append-only data history: corrections add entries, never rewrite (ADR-009).

### Known limitations (honest ones)

- Coverage is one record. The directory is a working pipeline around a seed dataset, by design.
- The watchlist is empty. The unlock machinery is live and tested; entries land when the documented-search bar is met.
- The iOS `.xcodeproj` is a structural placeholder (`project.json`) — the real project file is generated on first open per `ios/README.md`; committing Xcode's generated bundle was judged worse than a two-minute documented recipe.
- CI does not compile the Android/iOS apps (no first-party actions for it yet); local builds are the compile path.
- `android_auto/` and `watch/` carry byte-compatible crypto helpers that are deliberately unused until those surfaces gain a subscriber tier.
